# VEXA — пакет утверждённых разработок

Версия пакета: 1.0  
Дата фиксации: 06.11.2026

Это единый документальный пакет по решениям, которые были подтверждены в обсуждениях проекта VEXA. Он предназначен как исходная точка для продолжения разработки и передачи контекста между этапами.

## Состав
- `docs/01_APPROVED_DECISIONS.md` — утверждённые бизнес-правила.
- `docs/02_ARCHITECTURE.md` — целевая архитектура платформы.
- `docs/03_DATABASE_DESIGN.md` — согласованный каркас модели данных.
- `docs/04_ORDER_AND_FINANCE_FLOWS.md` — жизненный цикл заказа и финансовая логика.
- `docs/05_ROADMAP_AND_STATUS.md` — текущий статус и последовательность дальнейших работ.
- `docs/06_VPS_AND_DEPLOYMENT_GUIDE.md` — безопасный порядок проверки и будущего развёртывания.
- `docs/07_OPEN_QUESTIONS.md` — вопросы, которые нельзя считать утверждёнными без отдельного решения.

## Важно
Этот архив фиксирует требования и проектные решения. Он **не является готовым исполняемым серверным приложением**, APK или дампом действующей базы данных. Не заменяйте им текущие файлы на VPS. Этап «ДЕЙСТВУЮЩИЙ VPS» отложен; действующий сервер не изменять до отдельного возвращения к этому этапу.
