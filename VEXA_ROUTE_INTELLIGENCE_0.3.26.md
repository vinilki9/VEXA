# VEXA Route Intelligence 0.3.26 — проверка дорожного графа

Основа: исходный архив 0.3.25. Добавлен **неизменяющий входной файл** валидатор `VEXA_MAP/tools/audit_navigation_graph.py` для уже созданного регионального MBTiles со схемой `vexa_navigation_schema=v1`.

## Проверка

```powershell
python VEXA_MAP/tools/audit_navigation_graph.py C:\VEXA\maps\central.mbtiles --region central
python -m unittest discover -s VEXA_MAP/tests -p 'test_graph_audit_0326.py' -v
```

Проверяются наличие таблиц, регион и версия схемы, количество узлов/рёбер, ссылки рёбер на узлы, корректность координат и положительные веса. Вывод — JSON; код возврата 1 при ошибках. Количество изолированных узлов выводится как диагностический показатель (не автоматическая ошибка, поскольку отдельные компоненты могут быть допустимы).

**Ограничения:** текущая схема v1 не хранит запреты поворотов, уровни эстакад, полосы и геометрию каждого ребра. Поэтому ни один тест не доказывает корректность движения на московских развязках. Для реального графа Москвы и области нужны лицензионные исходные дорожные данные, конвертер с учётом ограничений поворотов, пространственный индекс и тестовые маршруты. Никаких данных Москвы в архив не добавлено. Android-приложение не менялось, APK не собирался. VPS/GitHub не изменялись.
