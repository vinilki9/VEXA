# 06. VPS и инструкция безопасной работы

## ВНИМАНИЕ: действующий VPS пока не трогать
Пользователь ранее обозначил этап проверки текущего VPS как **«ДЕЙСТВУЮЩИЙ VPS»** и отложил его. Поэтому эта инструкция описывает порядок будущей проверки, но не является указанием выполнять команды сейчас.

## 1. Когда будет дано отдельное разрешение вернуться к VPS
Сначала выполнить только диагностические команды, не меняющие состояние системы:

```bash
whoami
hostname
cat /etc/os-release
pwd
which systemctl
systemctl --version
```

Затем изучить службы:

```bash
sudo systemctl list-units --type=service --all
```

И только после этого искать названия, связанные с приложением:

```bash
sudo systemctl list-units --type=service --all | grep -Ei 'taxi|vexa|uvicorn|fastapi'
```

Если `grep` отсутствует, можно просмотреть полный список без фильтра. Сообщение «отсутствует плагин apt» не является нормальным результатом этой команды: `apt` не требуется для `systemctl` или `grep`. Нужно выяснить, в какой именно оболочке/панели выполняется команда, и получить точный текст ошибки.

## 2. Что не выполнять без отдельного подтверждения
Не выполнять до проверки:
```bash
sudo systemctl restart ...
sudo systemctl stop ...
sudo systemctl disable ...
sudo apt upgrade
sudo apt autoremove
alembic upgrade head
```

Не менять `.env`, конфигурации reverse proxy, systemd unit-файлы и файлы приложения до резервного копирования и понимания текущей схемы.

## 3. Будущий безопасный порядок развёртывания
1. Получить явное разрешение на работу с этапом «ДЕЙСТВУЮЩИЙ VPS».
2. Установить фактическую ОС, пользователя, каталог проекта и способ запуска.
3. Определить текущий процесс/службу и проверить журналы.
4. Сделать резервную копию кода, конфигурации и базы данных.
5. Подготовить отдельное тестовое окружение.
6. Проверить зависимости и конфигурацию приложения.
7. Применять миграции только после проверки резервной копии и совместимости.
8. Запустить/перезапустить сервис по согласованному плану.
9. Проверить health endpoint, API, логи и клиентское подключение.
10. Зафиксировать способ отката.
