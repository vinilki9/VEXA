# VEXA — единый дизайн-системный стандарт 0.3.5

**Главный брендовый цвет** `#20C6B7` (бирюзовый). Дополнительные: графит `#111827`, тёмно-синий `#1E293B`, светлый фон `#F5F7FA`, текст `#64748B`. Исходный реестр: `design/tokens.json`.

## Внедрено в этом этапе

- Client Android: фирменный оттенок 0xFF20C6B7 и настроенная Material3 lightColorScheme, адреса API/карт под локальный и production-режим.
- Driver Android: тот же бирюзовый акцент в Material3, согласованный цвет ошибки; ночная, светлая и системная темы присутствуют в ручной разметке интерфейса, но полной синхронизации с Material3 ещё нет.
- Dispatcher Web: единые CSS-переменные, уточнённые карточки и навигация, состояния hover/focus, адаптивность и честный индикатор подключения к Backend.
- Platform Admin: тот же оттенок бирюзового, системные шрифты без загрузки Google Fonts (важно для локальной установки), видимый клавиатурный фокус, поддержка уменьшения анимаций, повторная проверка сессии при временной недоступности сервера.

## Состояния, которые нужно показывать явно

- Загрузка / пустой список / сетевой сбой / отказ в доступе / повторение операции.
- Подключение к карте не равнозначно готовности карт; пока отсутствуют MBTiles/OSRM, интерфейс должен предупреждать об ограничениях.
- Не показывать «онлайн», пока API не вернул фактическое здоровье сервиса.
- Не обещать работающие модули: в панели главного администратора финансы, пользователи, заявки и глобальные настройки пока показываются как будущие разделы.

## Дальнейший дизайн-долг

Полноценные автоматическая/светлая/тёмная темы **во всех** продуктах пока не реализованы одинаково. Нужна унификация экранов авторизации, типографики, форм и предупреждений, тесты контрастности WCAG, реальные Android screenshot/UI-тесты и браузерная проверка на мобильных/настольных размерах. Текущий этап **не подтверждает** визуальную идентичность после реальной сборки.
