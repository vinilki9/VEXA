# VEXA 0.3.38 — общая правовая информация для всех приложений

**Статус:** проект для юридической экспертизы. Не публиковать как действующую правовую документацию, пока не указано юридическое лицо, контакты, модель отношений и не согласованы сроки обработки/хранения данных.

## Архитектура

В `backend/app/legal_documents_catalog.json` добавлены 6 документов `role="common"`, `kind="reference"`, `required=false`. API `GET /api/v1/legal/roles/{role}` показывает их вместе с документами конкретной роли. API `GET /api/v1/legal/roles/{role}/{id}` возвращает полный текст, который можно открывать в существующем экране документов. Подтверждения через `validate_acceptances` принимают **только документы конкретной роли**: общие справочные страницы не создают ложные обязательные согласия.

## Общие темы

- Защита персональных данных и основания обработки (152-ФЗ).
- Информационная безопасность (149-ФЗ).
- Электронные документы и виды электронных подписей (63-ФЗ, ГК РФ).
- Претензии и обращения (ГК РФ, Закон РФ №2300-1 в пределах применимости).
- Реклама и добровольные согласия (38-ФЗ).
- Авторские права на ПО и карты (часть IV ГК РФ, условия лицензий данных).
