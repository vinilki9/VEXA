# VEXA Legal UI 0.3.40 — локальный этап

## Реализовано
- В Dispatcher и Platform Admin появились разделы юридических документов с чтением полного текста, историей и подтверждением актуальной редакции через авторизованный API.
- Интерфейсы работают с существующими маршрутами `/api/v1/legal/roles/{role}` и `/api/v1/legal/account/{role}/{pending,history,accept}`.
- Запрос подтверждения содержит точную версию и SHA-256; сервер обязан проверять соответствие актуальному каталогу.
- Документы обозначены как черновики; **никаких юридических гарантий или действующих договоров из них делать нельзя**.

## Не реализовано в этом выпуске
- Сборка Android и UI принятия обновлений в Android Driver и Navigator.
- Автоматическая блокировка рабочих операций при изменении обязательного договора; до утверждения документов включать такую блокировку нельзя.
- Утверждение реквизитов юрлица, обработка отзывов согласий, доказуемая долговременная архивизация.
- Интеграционные тесты с работающей PostgreSQL.

## До коммерческого запуска
1. Российский юрист утверждает актуальные редакции с реквизитами VEXA и правовыми основаниями для каждого типа обработки.
2. Редакции публикуются, для них вычисляются новые SHA-256; в клиентских интерфейсах снимается маркировка черновика **только после** утверждения.
3. Добавить согласованный режим enforce-only-required на Backend, запрет обхода через альтернативные API, аудит принятых версий, управление отзывом необязательных согласий.
4. Интеграционно проверить все роли и сценарии повторного принятия.

Изменения выполнялись только в локальной копии; VPS и GitHub не менялись.
