# Готовность функций VEXA 0.3.8

Основа — текущий набор исходников 0.3.7 и дополнительные функции 0.3.8.

| Функция | Состояние | Ограничение |
|---|---|---|
| Client: история поездок и повтор маршрута | Код в 0.3.8, подтверждён API-контракт | Нет проверки APK, реального SMS и PostgreSQL |
| Client: новый заказ после завершённой поездки | Код в 0.3.8 | Нет Android E2E теста |
| Driver: переход во внешний навигатор | Код в 0.3.8 | Это не встроенная офлайн-навигация VEXA MAP |
| Driver: кнопка звонка пассажиру | Код в 0.3.8 | Пользователь вручную подтверждает звонок в телефоне |
| Client/Driver: основные заказ, смены, финансы, настройки | Код предыдущих версий | Нужны APK и реальные интеграционные испытания |
| Backend, Dispatcher, Admin, VEXA MAP, инфраструктура | Сохранены | Нет полного Docker/PostgreSQL/browser/E2E теста; не весь функционал закончен |

Статические тесты не заменяют компиляцию Android и проверки на устройстве.
