# План приёмочных испытаний

- [ ] Регистрация/авторизация пассажира по телефону.
- [ ] Создание заказа идемпотентно при повторном запросе.
- [ ] Проверка тарифа на стороне Backend; клиент не может подменить стоимость.
- [ ] Проверка всех тарифных сеток и исключений по городам.
- [ ] Проверка допуслуг +100 ₽ и анонимного заказа +100 ₽.
- [ ] Один заказ не назначается двум водителям при конкурентном принятии.
- [ ] Отказ водителя не снижает рейтинг.
- [ ] Диспетчер может переназначить заказ; действие попадает в аудит.
- [ ] GPS/статусы приходят в реальном времени.
- [ ] Завершённая поездка сохраняет снимок тарифа и условий.
- [ ] Комиссия рассчитывается в копейках; наличные отражаются долгом водителя.
- [ ] Проверка ролей и изоляции организаций/филиалов.
- [ ] Проверка дневной/ночной/системной темы Driver и сохранения выбора.
- [ ] Голосовые команды ограничены тремя утверждёнными фразами.
- [ ] SOS не активируется случайным касанием.
- [ ] Резервная копия восстанавливается на чистой БД.
- [ ] APK подписаны владельцем проекта и проверены на целевых устройствах.
