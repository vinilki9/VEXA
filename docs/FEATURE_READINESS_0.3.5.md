# VEXA — матрица готовности после 0.3.5

| Возможность | Подготовлено в исходниках | Что нужно доказать перед релизом |
|---|---|---|
| Client: вход, заказ, статус, стоимость | Код и серверные маршруты | APK, SMS и E2E с реальной БД, сетевые ошибки, финансовая точность |
| Driver: вход, предложение 13 с, статусы, GPS, финансы | Код и обработка повторов статуса | APK, фоновые разрешения, реальный GPS, отказоустойчивость, реальная выплата |
| Dispatcher: заказы, назначение, карта | React интерфейс + API | Web build, роли и доступность страниц, реальное назначение |
| Admin: города, организации и вход | Базовые рабочие экраны | Web build, сценарии прав и миграции; финансы/заявки/пользователи ещё заглушки |
| VEXA MAP: MBTiles, адреса, OSRM | Локальный сервис, серверные тесты | Настоящие геоданные, стили векторных тайлов, граф для всей РФ, сквозная навигация |
| Local Windows 11 | Docker Compose | Запуск на ПК, сеть Wi-Fi для телефонов, резервирование |
| Real Linux server | Новый `compose.production.yml`, Caddy HTTPS, миграции и backup | DNS, TLS, сервер, restore-тест, мониторинг, безопасность и нагрузочные проверки |
| Бренд VEXA | Общие дизайн-токены, обновления CSS/Compose | UI-скриншоты, тесты тем, контрастность, доступность |

**Не реализовано полностью:** полноценные платежи/возвраты, пуши и SMS в реальных окружениях, все административные модули, производство спутниковых и 3D-карт, готовые офлайн-регионы РФ, полный CI/CD c signed Android release и production мониторинг. Поэтому версия 0.3.5 — **исходный проект с подготовленной инфраструктурой**, не готовый к публичному запуску агрегатор.
