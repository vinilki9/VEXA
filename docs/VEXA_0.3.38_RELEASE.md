# VEXA 0.3.38 — общая юридическая база

- Добавлены 6 общих читаемых справочных документов для Client, Driver, Navigator, Dispatcher, Platform Admin.
- Реализована выдача общих документов через действующие API документов по ролям.
- Исключено использование общих справочных страниц как обязательных согласий при регистрации.
- Добавлены регрессионные тесты видимости и исключения общих документов из согласий.
- Без миграции БД, без изменения рабочей системы. Тексты — черновики до юридического утверждения.
