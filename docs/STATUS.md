# Статус комплекта

## Что включено сейчас
- Исходный каркас двух Android-приложений.
- React/TypeScript панель с демонстрационными данными.
- FastAPI каркас с health, тарифами и демонстрационным созданием заказа.
- SQL стартовая схема и JSON тарифы.
- Docker Compose и Nginx шаблон.
- Документация согласованных требований, сборки и испытаний.
- Единая визуальная палитра VEXA: бирюзовый / графит / тёмно-синий / светлый.

## Что НЕ готово
- APK не собраны и в архив не включены.
- Нет production-подписи Android.
- Нет реального подключения 2GIS, геолокации/GPS, картографического маршрута.
- Нет реального автоматического назначения, WebSocket-трекинга и диспетчерской очереди.
- Нет интеграций карт/СБП/эквайринга/SMS/push/телефонии.
- Не завершены роли/авторизация, tenant isolation, Alembic миграции, финансовые расчёты, аудит и тесты.
- Демонстрационные данные не являются реальными заказами.
- VPS не проверялся и не изменялся.

## Что требуется до production
1. Утвердить открытые бизнес-правила из `DECISIONS_AND_REQUIREMENTS.md`.
2. Реализовать модели, миграции, авторизацию и tenant isolation.
3. Реализовать pricing engine с целыми копейками и тестами.
4. Реализовать транзакционное назначение и idempotency.
5. Подключить выбранных провайдеров карт, платежей, SMS/push и телефонии.
6. Завершить приложения и диспетчерскую панель, интегрировать API.
7. Пройти end-to-end сценарий заказ → назначение → поездка → завершение → комиссия/выплата.
8. Пройти security, нагрузочные и backup/restore тесты.
9. Собрать debug APK и подписанный release APK в доверенной среде.
10. Только после отдельного согласования — развернуть на VPS.
