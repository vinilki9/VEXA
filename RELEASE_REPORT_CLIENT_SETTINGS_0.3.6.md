# VEXA Client 0.3.6 — настройки приложения

Дата: 21 ноября 2026. Основа: полный исходный проект `VEXA_TAXI_SERVER_READY_SOURCE_0.3.5.zip`. Изменён **только Android Client** и добавлены тесты/документация. Backend, Driver, MAP, Dispatcher, Admin и конфигурация серверов остаются из 0.3.5.

## Реализовано

- Кнопка **⋮** в правом верхнем углу карты на главном экране пассажира; подпись для TalkBack: «Открыть настройки приложения». Кнопка размером 48 dp со светлой/тёмной подложкой.
- Полноэкранная страница **«Настройки»** с верхней кнопкой «Назад»; аппаратная кнопка Android Back тоже закрывает страницу. Страница отображается поверх текущего заказа, чтобы не сбрасывать введённые адреса, маршрут и состояние заказа.
- **Профиль**: отображение телефона авторизованного пользователя, вход через существующий `PassengerAuthDialog` (реальные API), выход с подтверждением и очисткой защищённой сессии Android Keystore. Серверное удаление аккаунта не реализовано.
- **Внешний вид**: светлая, тёмная и системная тема. Предпочтение сохраняется после перезапуска в `SharedPreferences`, ключ `theme_mode`.
- **Заказы и оплата**: способ оплаты по умолчанию, совпадающий с уже существующими вариантами в форме заказа. Выбранное значение сохраняется, при открытии формы используется как первоначальное. **Это не подключение платёжного шлюза:** карта/СБП по-прежнему требуют серверной платёжной интеграции.
- **Карта и геопозиция**: фактический статус Android разрешения на геопозицию и открытие системной страницы разрешений; статус обновляется после возвращения в приложение.
- **О приложении**: версия Android Client и сведения об используемом VEXA MAP/MapLibre; без вымышленных ссылок на поддержку.
- В существующем экране заказа светлая/тёмная схема применяется к основным поверхностям и тексту.

## Что ещё нужно проверить

- **Не подтверждена компиляция APK:** в среде недоступен `services.gradle.org`, Gradle Wrapper не смог скачать Gradle 8.13. Не утверждаем, что Kotlin-код собран.
- Запуск на Android: отображение экрана, кнопка на карте, смена темы, возвращение без сброса формы, реальный вход по SMS и выход.
- Работа безналичной оплаты, пуш-уведомлений, удаление личных данных и история поездок не добавлены, поскольку отсутствует подтверждённый серверный API. Не отображаем неработающие элементы настроек.

## Сборка для проверки на Windows 11

1. Распаковать архив и открыть `android/client` в Android Studio.
2. Установить Android SDK 35, JDK 17 и зависимости Gradle; настроить адреса Backend и VEXA MAP в `gradle.properties` или параметрах Gradle согласно `README_LOCAL_SETUP.md`.
3. Запустить debug-сборку Client через Android Studio на реальном Android-устройстве или эмуляторе; проверить перечисленные пункты.
4. Для release продолжает действовать требование HTTPS и явных `vexaReleaseApiBaseUrl` / `vexaReleaseMapBaseUrl` из 0.3.5.

Исходный ZIP 0.3.5, GitHub, VPS и локальный сервер пользователя не менялись.
