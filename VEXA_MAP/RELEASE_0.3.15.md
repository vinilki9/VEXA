# VEXA MAP 0.3.15 — региональные офлайн-пакеты (этап инфраструктуры)

**База:** VEXA Taxi 0.3.14 Design System. **Разработка:** локально, без изменения Windows, GitHub и VPS.

## Реально реализовано

- Единый каталог восьми федеральных округов России и доступность по каждому пакету.
- Генератор манифестов `--publish-region <region_id> --data-version <version>` для подготовленных лицензированных растровых MBTiles. Метаданные: версия, формат, диапазон масштабов, размер, SHA-256, атрибуция.
- Ручная потоковая полная проверка контрольной суммы `--verify-region <region_id>`.
- HTTP API каталога `/v1/offline/catalog`, манифестов `/v1/offline/regions/{region_id}/manifest`, скачивания `/v1/offline/regions/{region_id}/download`.
- Потоковая передача с поддержкой `HTTP Range`, возобновления по `If-Range`/`ETag`, `HEAD`, ответов `206`, `304`, `416` и ограниченного размера буфера (256 КиБ).
- Скачивание **явно выключено по умолчанию** (`VEXA_MAP_SERVE_OFFLINE_PACKS=0`). Включать лишь внутри частной сети/за аутентифицированным шлюзом.
- Dockerfile включает новый модуль; параметры внесены в конфигурации local и production.
- Веб-стиль VEXA MAP сохраняет утверждённую графитово-бирюзовую палитру 0.3.14.

## Как подготовить один пакет

Нужен **настоящий**, разрешённый к распространению пакет `VEXA_MAP/data/regions/central.mbtiles` (его нет в ZIP).

```powershell
python VEXA_MAP/server/vexa_map_server.py --mbtiles VEXA_MAP/data/regions --publish-region central --data-version 2026.11
python VEXA_MAP/server/vexa_map_server.py --mbtiles VEXA_MAP/data/regions --verify-region central
```

Каталог можно проверить после запуска сервера по `/v1/offline/catalog`. Отсутствующие округа показываются как `available: false` — никакой фиктивной карты России не создаётся.

- `python -m unittest discover -s tests -q` — **22 теста пройдены** (проверки контракта исходников).
- `python -m compileall -q VEXA_MAP/server` — успешно.
- CLI publish/verify проверен на синтетическом тестовом MBTiles, оба вызова завершились с кодом 0.
- Синтетические тесты не доказывают совместимость настоящих многогигабайтных карт и телефона.

## Что НЕ реализовано

1. Файлы реальных карт России / покрытия населённых пунктов, почтовых адресов и межрегионального дорожного графа в архиве отсутствуют.
2. Самостоятельное скачивание, управление свободным местом и показ MBTiles в мобильных Client/Driver пока не подключены. **Скачанный MBTiles нельзя автоматически отобразить в MapLibre Native без отдельного движка/адаптера.**
3. 3D-рельеф, спутниковые изображения, полноценная голосовая навигация и обновление карт по дельтам не реализованы.
4. На публичном сервере потребуются лицензии на данные, HTTPS, аутентификация/подписанные URL, квоты, контроль доступа, мониторинг и тесты нагрузки.
5. Хеш SHA-256 не заменяет криптографическую подпись издателя манифеста. В релизе необходим механизм доверенных подписей.
6. Android APK, веб-сборки и Docker-контейнеры не собирались и не запускались в ходе этого этапа.
