# VEXA MAP 0.3.17 — показ скачанных карт в Client и Driver

## Назначение

В обоих Android-приложениях к экрану карты подключён **общий** модуль `android/shared/vexa-map-offline`. Ранее он скачивал региональные MBTiles, но не отображал их. Теперь при наличии установленного **растрового** MBTiles MapLibre получает тайлы непосредственно с телефона. Работа этого источника не требует Wi-Fi, сотового интернета, серверной авторизации или обращения к VEXA Backend. Обе программы продолжают хранить свои пакеты **раздельно** в собственных папках `filesDir/vexa-map/offline/`.

## Схема работы

1. Откройте **Client → Настройки → Офлайн-карты России** или **Driver → Настройки → Навигация VEXA MAP → Офлайн-карты**.
2. Загрузите округ, опубликованный VEXA MAP, с проверкой SHA-256 и возможностью докачки.
3. Для установленного растрового пакета нажмите **«Показать на карте»**. Приложение сохранит выбор округа и режим `Офлайн`. Вернитесь на главный экран карты.
4. На карте есть кнопка `Карта: Авто / Онлайн / Офлайн`. В режиме `Авто` при отсутствии проверенного интернета отображается установленная растровая карта; можно принудительно включить офлайн-режим.
5. Локальный сервер тайлов внутри **самого приложения** связывается только с `127.0.0.1`, читает MBTiles через SQLite **только для чтения**, конвертирует XYZ в TMS. Сами тайлы через сеть не загружаются.
6. Если у пакета есть metadata `center` или `bounds`, карта центрируется на соответствующей области. Все восемь федеральных округов поддерживаются как отдельные установленные пакеты.

## Поддерживаемые данные

- **Уже поддерживается:** растровые MBTiles с `metadata.format = png`, `jpg`/`jpeg` либо `webp`; таблица или view `tiles(zoom_level, tile_column, tile_row, tile_data)` с TMS-строками; `metadata.minzoom`, `metadata.maxzoom`, желательно `metadata.center` либо `metadata.bounds`, `metadata.attribution`.
- **Не поддерживается в 0.3.17:** векторные PBF MBTiles (необходимы отдельный векторный стиль, локальные шрифты/иконки и обработка сжатых тайлов), GeoJSON как готовый MBTiles, спутниковые снимки без соответствующих лицензий.
- Если скачан PBF-пакет, он остаётся на телефоне, но кнопка **«Показать на карте»** для него скрыта и появляется объяснение.
- Масштабы и географическое покрытие определяются содержимым MBTiles: **исходный архив не содержит реальных карт России**.

## Безопасность

- HTTP источник `127.0.0.1` слушает **только loopback**, а не локальную Wi-Fi сеть или интернет. В release-конфигурации Android разрешён cleartext только к `127.0.0.1`; остальные HTTP-адреса остаются заблокированными.
- Клиентский загружатель по-прежнему требует HTTPS в release (HTTP разрешён только для debug).
- SHA-256 проверяется при установке пакета, при необходимости пользователь может вручную выполнить повторную проверку. Это **не является подписью издателя** — публичная доставка пакетов требует криптографически подписанного каталога.
- Локальный loopback-сервис не требует авторизации и отдаёт только неперсональные тайлы карты; другие процессы на том же устройстве потенциально могут подключиться к найденному порту. В нём нет заказов, координат GPS или учётных данных.

## Что не нужно путать с офлайн-картой

- **Офлайн-поиск адресов не сделан.** Нужен отдельный локальный геокодер/индекс населённых пунктов и адресов, версионируемый по округам.
- **Офлайн-маршрутизация не сделана.** Нужен дорожный граф по округам и мобильный маршрутизатор с пересечениями округов. Нельзя считать прямую линию по карте действительным дорожным маршрутом.
- GPS самого устройства работает без интернета, если есть спутниковый сигнал, но передача GPS и заказов в Backend требует связи. Для Driver в офлайн-режиме не выполняется запрос маршрута к онлайн OSRM и показывается понятное предупреждение.
- Онлайн-стиль и весь цикл заказов не заменены — переключаются лишь источники отображения карты.

## Тестирование и ограничения

- `python -m unittest discover -s tests -q`: 36 тестов.
- `python -m unittest discover -s VEXA_MAP/tests -q`: 23 теста.
- `OfflineTileMath.kt` проверен автономным `kotlinc` + Java — 12 утверждений.
- `OfflineMbtilesServer.kt` и `OfflineMapMode.kt` проверены автономным `kotlinc` с минимальными **тестовыми заглушками Android API** — это проверка синтаксиса, а не сборка Android SDK и не проверка SQL на Android.
- **В этой среде нет Android SDK и gradle-wrapper.jar:** полноценных APK, визуального рендеринга и тестов на реальных телефонах пока нет.
- Для настоящей проверки нужны опубликованный **растровый** региональный MBTiles, Android Studio (Gradle Sync + `assembleDebug`), работа на телефоне **в режиме полёта**, карта в нужных координатах и проверка переключения после обновления пакета.
