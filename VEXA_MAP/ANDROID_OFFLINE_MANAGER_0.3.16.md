# VEXA MAP 0.3.16 — офлайн-пакеты в Client и Driver

## Реализовано в исходниках

- Единый Android Library модуль `android/shared/vexa-map-offline/`, используемый двумя независимыми Android Studio проектами (`android/client`, `android/driver`).
- В настройках **VEXA Client → Карта и геопозиция → Офлайн-карты России** и **VEXA Driver → Навигация VEXA MAP → Офлайн-карты** доступен общий экран.
- Экран отображает **8 федеральных округов**: Центральный, Северо-Западный, Южный, Северо-Кавказский, Приволжский, Уральский, Сибирский, Дальневосточный.
- Каталог загружается из `GET /v1/offline/catalog`, версия/размер/SHA-256 сверяются с опубликованным `GET /v1/offline/regions/{id}/manifest`.
- Скачивание `/v1/offline/regions/{id}/download`: потоковая запись в приватную папку приложения с прогрессом, `Range`/`If-Range` для докачки. Кнопка **Пауза** отменяет текущую загрузку и сохраняет частичный файл. Следующий запуск продолжает загрузку, если SHA-256 манифеста не изменился. Если тело скачано полностью, проверка может завершиться без повторной передачи.
- Перед началом проверяется доступное место с резервом, после скачивания выполняется **SHA-256 всего файла**. До окончания проверки новый пакет не подменяет старый; установка через атомарное перемещение.
- Показываются установленные версии и обновления; пользователь может вручную проверить SHA-256 установленного файла или удалить пакет с подтверждением.
- Без интернета установленные пакеты видны в списке. Их файлы лежат в `filesDir/vexa-map/offline` **отдельно для Client и отдельно для Driver**. Android storage permission не нужна; файлы удаляются вместе с приложением.
- Для release обязательно HTTPS; разрешение HTTP только в debug (для частной сети во время тестирования). Перенаправления по HTTP отключены.

## Нужные действия для реальной загрузки

1. Создать настоящие лицензированные MBTiles по округам и опубликовать их на отдельном сервере VEXA MAP с `--publish-region`. В ZIP исходников карты не входят.
2. Включить **только на защищённом сервере / доверенной локальной сети** `VEXA_MAP_SERVE_OFFLINE_PACKS=1`; по умолчанию скачивание на VEXA MAP отключено. Публичное развёртывание потребует авторизованного шлюза, подписи манифеста, квот и контроля пользователей.
3. Настроить правильный `VEXA_MAP_BASE_URL` в Android: debug `-PvexaServerHost=...`, release `-PvexaReleaseMapBaseUrl=https://.../maps`.
4. Открыть Android Studio из `android/client/` или `android/driver/`: Gradle должен подключить библиотеку из соседней `android/shared` при сохранении структуры всего ZIP.

## Важные ограничения

- **Это менеджер загрузок, не движок офлайн-навигации.** MapLibre Native пока показывает онлайн-стиль; для локального отображения MBTiles понадобится адаптер тайлов или альтернативный движок. Для маршрутов без сети нужен отдельный офлайн-граф и маршрутизатор. Скачивание только MBTiles не позволяет искать адреса и строить маршруты офлайн.
- Обновление показывает/скачивает целый пакет версии; **дельта-обновления** ещё не сделаны.
- Загрузка в этой версии идёт только при открытом экране. При его закрытии загрузка приостанавливается и позже возобновляется; фоновые уведомления/WorkManager ещё не подключены.
- SHA-256 проверяет целостность относительно каталога сервера, но **не является доверенной криптографической подписью издателя**. Без подписей манифестов публичный CDN не готов.
- Нет гарантий полноты России, спутниковых снимков или 3D: нужны данные и лицензии.
- **Сборка Android APK не подтверждена:** в среде отсутствуют Android SDK / рабочая загрузка Gradle-зависимостей. Нужен Gradle Sync и сборка на Android Studio, затем тесты на телефоне.

## Известный блокер Gradle Wrapper

В исходном архиве 0.3.15 присутствуют `gradlew`/`gradlew.bat` и `gradle-wrapper.properties`, но **нет `gradle/wrapper/gradle-wrapper.jar`** в обоих Android-проектах. При необходимости восстановите официальный Gradle Wrapper (через доверенный Gradle 8.13 и команду `gradle wrapper`) перед запуском `gradlew`; не скачивайте неизвестный JAR. В этой среде нет Android SDK/Gradle, поэтому реальная сборка APK здесь не подтверждается.
