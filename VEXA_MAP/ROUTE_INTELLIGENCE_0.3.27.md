# VEXA Route Intelligence 0.3.27 — пространственный индекс

## Реализовано
- Генератор регионального MBTiles создаёт SQLite RTree `vexa_node_rtree` по координатам узлов.
- Android использует RTree при выборке узлов ограниченного коридора и сохраняет совместимость с пакетами v1 без RTree.
- Аудит выявляет расхождение количества записей RTree и узлов.
- Тест проверяет пространственную выборку на синтетических данных.

## Ограничения и дальнейшие задачи
- Это индекс узлов, **не** индекс дорожных сегментов и **не** полноценный map matching.
- Текущий маршрутизатор ограничен коридором и 90 км, а также лимитами узлов/рёбер. Вся Москва и область пока не покрыты работающей маршрутизацией.
- Поворотные ограничения, односторонность, уровни развязок и легальные места посадки должны поступать из лицензированных дорожных данных. Схема v1 их не содержит.
- Для промышленной навигации далее нужны ориентированный граф с идентификаторами дуг, ограничения переходов между дугами, индекс сегментов, многокандидатный map matching и тесты с реальными треками.
- Публикация пакетов допускается только после проверки прав на исходные данные, целостности и дорожных ограничений.
- Серверы и GitHub не затрагиваются. APK и реальные поездки не проверены.
