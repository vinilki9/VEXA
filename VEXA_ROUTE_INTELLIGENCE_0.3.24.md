# VEXA Route Intelligence 0.3.24 — этап 4

База: VEXA Route Intelligence 0.3.23. Изменения только в локальных исходниках.

## Добавлено
- `android/shared/vexa-map-offline/src/main/java/ru/vexa/offline/RoadAwareMatching.kt`: RoadAwareMatcher, RoadEdge, RoadMatch — оценка кандидатов дорожного графа по расстоянию, направлению движения, известному уровню дороги и предыдущему ребру. Возвращает `ambiguous` и `confident`, чтобы не выдавать сомнительное сопоставление за точное.
- `VoicePromptGate`: однократная подсказка перед манёвром с порогом по скорости; **не** озвучивает сама, требует подключения Android TextToSpeech и данных манёвров.
- `tests/RoadAwareMatchingTest.kt`: JVM-тесты направления, неоднозначности, запрета проезда, уровня дороги и подавления повторных подсказок.

## Ограничения
- Это кандидатный геометрический matcher, **не** полноценный HMM/Viterbi graph map matching; дорожные рёбра и уровни должны поступать из настоящего маршрутизатора/OSM-графа.
- На перекрывающихся дорогах без метаданных функция корректно отмечает неоднозначность; не заявляет точное определение эстакады, полосы или тоннеля.
- В Android Driver этот модуль пока не подключён: требуется адаптер дорожного графа и жизненного цикла маршрута. Существующее геометрическое сопоставление из 0.3.23 остаётся неизменным.
- Дорожные данные Москвы и области, полные офлайн-пакеты, голосовой движок и подтверждение законности посадки в архив не добавлялись.
- APK не собран, реальные GPS-поездки не проверены.

## Проверка
`kotlinc RouteIntelligence.kt RouteMatching.kt RoadAwareMatching.kt RoadAwareMatchingTest.kt -include-runtime -d tests.jar && java -jar tests.jar`
В этой рабочей среде: `RoadAwareMatching tests: OK`.

## Следующие интеграционные задачи
1. Адаптер OfflineGraph -> RoadEdge с направлением, layer, access, геометрией; тесты мостов, тоннелей, параллельных дорог и петель.
2. Подключение matcher в DriverMap только при уверенном совпадении; неоднозначность не должна автоматически запускать reroute.
3. Генерация манёвров из графа, Android TextToSpeech с очередью и отключением при смене заказа.
4. Проверка на реальных логах с согласия водителей; не сохранять идентификаторы и точные треки по умолчанию.
