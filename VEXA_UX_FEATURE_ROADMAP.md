# VEXA — roadmap функциональных модулей после UX phase 1

**Принцип:** самостоятельный интерфейс VEXA, карта в центре пользовательского сценария, одинаковые статусы и деньги на сервере. Дизайн не копирует оригинальные логотипы, тексты и композицию сторонних приложений.

| Функция | Статус 0.3.13 | Что требуется для включения |
|---|---|---|
| Клиент: карта + панель адресов | Есть, улучшено | Проверить Android-сборку, UX на устройствах |
| Дом / Работа | Сделано локально | Позже облачная синхронизация и миграция из телефона |
| Уточнение точки подачи | Сделано как комментарий | Позже pin-placement и сторона улицы в VEXA MAP |
| Поделиться поездкой | Сделано текстом | Для живого отслеживания — токен доступа и отзыв |
| Автоподбор машины | Каркас 0.3.10 | Реальные тесты worker на PostgreSQL, гонки, отказоустойчивость |
| Заказ заранее | Не реализовано | Таблица расписания, воркер предварительного поиска, перенос/отмена, часовой пояс |
| Быстрее / Экономно | Не реализовано | SLA ожидания, стратегия подбора, стоимость и прозрачный прогноз |
| Остановки и ожидание | Тарифные параметры 0.3.12 | События остановок, фактическое время, подтверждение пересчёта |
| Центр безопасности и SOS | Не реализовано | Протокол безопасности по стране, экстренный контакт, аудит событий |
| Живое отслеживание | Не реализовано | Сервис GPS/ETA, выдача ограниченных разрешений на чтение |
| Семья | Не реализовано | Роли, согласия, список участников, расходы, права детей |
| Корпоративные поездки | Не реализовано | Организации, лимиты, акт/счёт/отчёты, политики поездок |
| Чат/звонки | Частично (набор номера) | Прокси-телефония, чат, модерация, защита контактов |
| Поддержка/споры | Не реализовано полностью | Тикеты, SLA, журнал действий, возвраты |
| Лояльность | Не реализовано | Промокоды, правила злоупотреблений, учёт затрат |
| Предложить цену | Не реализовано | Согласование тарифа и местных правил, антифрод |
| Совместные поездки | Не реализовано | Matching, безопасность, тариф распределения, согласия |
| Driver: Перерыв | Сделано, серверное снятие с линии | Параметры смен, контроль усталости, локальные трудовые правила |
| Driver: Финансы | Имеются карточки | Реальные выплаты, сверка, чеки, ограничение доступа |
| Dispatcher: исключения | Есть часть инструментов | Очередь инцидентов, статусы SLA, назначение ответственных |
| Admin: управление рынками | Частично | Валюты, налоги, часовые пояса, филиалы, права и аудиты |
| VEXA MAP | MapLibre + тестовый map-api | Реальные лицензионные данные РФ, навигационный граф, обновления, offline, 3D |
| Реальный сервер | Конфигурация есть | CI, Gradle, npm, Docker, PostgreSQL, тесты backup/restore, TLS и мониторинг |

## Приоритет следующего цикла разработки

1. **0.3.14: Поездки по времени** — серверная схема расписания, работник поиска, уведомления и контроль пропуска времени.
2. **0.3.15: GPS, ETA и живое отслеживание** — безопасное получение, авторизация, просроченные координаты, права доступа, real-time.
3. **0.3.16: Безопасность и поддержка** — не декоративная кнопка SOS, а реальные маршруты эскалации, контакты, журнал и тесты.
4. **0.3.17: Семейные и корпоративные сценарии** — права и финансовые лимиты по аккаунтам.
5. **0.3.18+: Финансы, доступность и международная локализация** — валюты в минимальных единицах, правила оплаты/налогов по странам, i18n.

Эти версии — план, не обещание автоматического выполнения в фоне.
