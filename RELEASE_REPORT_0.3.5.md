# VEXA Taxi + VEXA MAP 0.3.5 — развитие и подготовка к переносу

Дата: 21 ноября 2026. Основа: `VEXA_TAXI_LOCAL_DEV_0.3.4.zip`.

## Конкретные изменения

1. **Production deployment:** отдельный `infrastructure/compose.production.yml` (НЕ подключать локальный `docker-compose.yml`), единственный публичный HTTPS gateway Caddy, внутренние DB/Redis/Backend/карты/веб-панели без опубликованных портов, Alembic `upgrade head` до запуска API, `/health` для проверки.
2. **Резервирование и защита:** `tools/backup_postgres.sh`, шаблон `.env.production.example`, локальная проверка `tools/release_preflight.py` для секретов, DNS/HTTPS/URL БД и согласованности OSRM. Private `backups/` и `.env.production` игнорируются Git.
3. **Android:** релизные Client/Driver получают отдельные HTTPS адреса API и VEXA MAP из Gradle параметров `vexaReleaseApiBaseUrl`/`vexaReleaseMapBaseUrl`, debug остаётся с локальным HTTP. Запрещён Android backup, чтобы ключи сессии не попадали в системные бэкапы. Номера версий приложений 0.3.5.
4. **Дизайн:** единая бирюзовая палитра `#20C6B7` и токены `design/tokens.json`, доработаны адаптивность, фокус, состояние кнопок веб-панелей, оформлены рекомендации по темам и ошибкам.
5. **Dispatcher:** город задаётся `VITE_CITY_CODE`; метка «сервер подключён» теперь зависит от фактического ответа `/health` Backend (локальный Nginx проксирует этот маршрут).
6. **Admin:** временный обрыв сети не воспринимается как недействительная учётная запись; показана возможность повторной проверки. Реальный отказ `401/403` по-прежнему завершает сессию. Убрано дублирующее описание интерфейса.
7. **Backend:** в production выключены Swagger/ReDoc/OpenAPI-страницы. CLI создания диспетчера теперь запрашивает пароль скрытно, с подтверждением, по аналогии с админом; удалены небезопасные примеры паролей.

- Новые проверки конфигурации и UI-контрактов релиза: **12 passed**.

- Статический Python `compileall`: пройден. Синтаксическая транспиляция основных React TSX: без синтаксических ошибок; **не** заменяет `npm run build`.
- Оба Docker Compose: YAML успешно разобран и проверена зависимость API от миграций. Проверки настоящим Docker Compose нет.
