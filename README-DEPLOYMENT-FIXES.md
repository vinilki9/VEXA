# VEXA — пакет исправлений конфигурации развёртывания

## Что исправлено

1. Backend Uvicorn слушает `0.0.0.0` внутри контейнера, а не внешний IP VPS.
2. Docker Compose использует корректное TCP-назначение порта API.
3. Добавлена сборка React-диспетчерской в статические файлы через Docker.
4. Для Vite установлен корректный публичный префикс `/dispatch/`.
5. Nginx-конфигурация разделяет `/dispatch/`, `/api/`, `/health` и `/docs`.
6. Dev/preview серверы Vite слушают `0.0.0.0`, а не HTTPS IP.

## Важно

Это пакет конфигурационных исправлений, а не готовая production-система.
Текущая диспетчерская в `dispatcher/src/main.tsx` по-прежнему демонстрационная:
она не получает реальные заказы и показывает тестовые показатели.
Текущий `backend/app/main.py` также содержит демонстрационные API-обработчики,
а не полноценную авторизацию, БД, очередь заказов и назначение водителей.

## Перед применением

- Сделайте резервную копию текущей конфигурации на сервере.
- Проверьте фактический способ запуска контейнеров на VPS.
- В `infrastructure/docker-compose.yml` API публикуется на `127.0.0.1:8000`.
  Для диспетчерской добавьте к сервису `dispatcher` публикацию
  `127.0.0.1:8081:80`, если используете приведённый Nginx snippet.
- Скопируйте блоки из `infrastructure/nginx-vexa.conf.example` внутрь
  существующего HTTPS server block. Не заменяйте TLS-сертификаты и текущие
  правила сайта без проверки.
- Значение `DATABASE_URL` должно соответствовать реально настроенной БД.
- Не добавляйте `.env`, пароли, ключи или сертификаты в GitHub.

## Проверки после сборки

Из каталога `infrastructure`:
- `docker compose config`
- `docker compose build api dispatcher`
- `docker compose up -d`

Проверить с VPS:
- `curl -fsS http://127.0.0.1:8000/health`
- `curl -I http://127.0.0.1:8081/`

После интеграции в существующий HTTPS Nginx:
- `https://109.120.184.20/dispatch/`
- `https://109.120.184.20/health`

Успешная сборка контейнеров не означает, что API уже реализует рабочую
диспетчеризацию. Не подключайте реальные заказы до реализации и тестирования
авторизации, сохранения данных, ролей и изоляции филиалов.
