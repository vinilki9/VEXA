# VEXA Taxi + VEXA MAP 0.3.1 — промежуточная техническая сборка

**Дата:** 21 ноября 2026 г. **Назначение:** интеграционная копия исходников для локального ПК, а не готовый APK или производственная система.

## Реально исправлено

- VEXA MAP принимает директорию `data/regions/*.mbtiles` и читает тайлы из нескольких региональных **растровых** пакетов. Конфликты форматов блокируются явно. Неоформленные векторные PBF не выдаются за отображаемую карту.
- Диспетчерская использует одноимённый маршрут `/maps/style.json` через Nginx к локальному `vexa_map`. Ссылки на тайлы учитывают локальный путь `/maps`. Удалена старая надпись «Карта 2ГИС».
- Из Client и Driver удалены устаревшие файлы `dgissdk.key`. Версия исходников Android повышена до 0.3.1. Существующие MapLibre-компоненты сохранены.
- Удалён оставшийся неиспользуемый серверный провайдер 2ГИС; маршруты VEXA рассчитываются через OSRM. Успешная подготовка маршрута на живой геобазе пока **не подтверждена**.
- В Docker Compose добавлен необязательный локальный контейнер OSRM с профилем `routing`, чтобы не поднимать пустой граф автоматически.
- Добавлены сценарии получения OSM.PBF одного федерального округа и локальной подготовки автомобильного графа (Windows PowerShell + Docker); загрузка данных и выполнение тяжёлой предобработки на ПК пользователя ещё **не осуществлялись**.
- Документация локального запуска и проверки обновлена, манифест файлов пересоздан.

## Проверки, подтверждённые в среде подготовки

- VEXA MAP: **11/11** тестов, включая XYZ/TMS, SQLite поиск, отсутствие OSRM, два отдельных региональных пакета, запрет смешанного формата, прокси HTTPS и вариант без доверия к прокси.
- Backend: профильные pytest-тесты маршрутизации, провайдеров, тарифов и расчёта: **42 passed, 14 subtests**.
- XML/JSON/Python/YAML синтаксис, ZIP, отсутствие ключа 2ГИС проверены статически.

## Осталось до реальной работы на телефоне

1. Загрузить/создать законные растровые MBTiles по округам; OSM.PBF сам по себе **не** предоставляет растровые тайлы.
2. Подготовить дорожные графы и межрегиональную маршрутизацию. Скрипт OSRM работает только с одним регионом за один запуск.
3. Создать полноценную поисковую базу адресов.
4. Скомпилировать Client/Driver через Android Studio и проверить на устройствах, включая GPS, авторизацию, тарифы и заказы. Android SDK в этой среде нет.
5. Проверить запуск PostgreSQL, Redis, Docker, Dispatcher и Backend на реальном локальном ПК.
6. Для Android release настроить HTTPS/TLS. Офлайн-пакеты на Android, 3D, спутниковые слои и полнота геоданных страны ещё не реализованы.

**Никакие действия на пользовательском ПК, VPS или в GitHub не выполнялись.** Изменения находятся только в новой копии проекта.
