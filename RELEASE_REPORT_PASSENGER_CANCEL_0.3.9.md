# VEXA Taxi 0.3.9 — промежуточное обновление исходников

Дата: 21 ноября 2026.
Основа: VEXA 0.3.8.

## Реализовано

- `POST /api/v1/passenger/orders/{order_id}/cancel`: пассажир вправе отменить только свой заказ в состояниях `new` и `accepted`.
- API требует действующую пассажирскую сессию. Чужой или отсутствующий заказ возвращает 404.
- Повторная отмена уже отменённого заказа идемпотентна: дублирующее событие не создаётся.
- Смена статуса, запись в `order_status_history` и отмена ожидающих предложений водителям выполняются в одной транзакции.
- На уровне базы данных используется блокировка строки заказа для PostgreSQL, чтобы снизить риск гонки с принятием предложения водителем.
- В VEXA Client добавлены кнопка «Отменить заказ», подтверждающий диалог и обработка ошибок сессии/сети/конфликта состояния.

## Ограничения

- Самостоятельная отмена пассажиром **после назначения водителя** намеренно заблокирована (HTTP 409): для этого потребуются бизнес-правила, расчёт компенсаций, уведомления и процедура работы с водителем/диспетчером.
- Автоматический подбор водителя сразу после создания заказа в этом выпуске не внедрён.
- Сквозная проверка работающих PostgreSQL, Docker, двух Android-устройств и веб-панелей не проводилась.
- APK не собран. Конкретное поведение клиента на устройстве не подтверждено.
- Никаких изменений работающего VPS, Windows, GitHub и production-БД не производилось.
