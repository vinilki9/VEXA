# VEXA MAP — миграция, этап 2

## Изменения
- Диспетчерская: сохранена замена MapGL 2ГИС на MapLibre GL JS из этапа 1.
- Driver: компонент `DriverMap.kt` переведён с 2ГИС на MapLibre Native Android, с маркером текущей позиции, кнопкой центрирования, запросом GPS-разрешений.
- Driver: удалена инициализация DGis в `VexaApplication.kt`, зависимости 2ГИС заменены на MapLibre.
- Driver: добавлено поле `BuildConfig.VEXA_MAP_STYLE_URL`. По умолчанию пустое. Для локальной проверки укажите доступный лицензированный URL стиля в Gradle, без секретов.
- Client: не изменён, пока зависит от 2ГИС для поиска и маршрутов.

## Важно
Это исходники промежуточного этапа, НЕ готовая замена карт во всех приложениях.
Реальный сервер тайлов, адресный поиск, маршруты, голосовая навигация, офлайн-пакеты и спутниковые данные отсутствуют.
Полная Gradle-сборка, запуск на телефоне и диспетчерская сборка не подтверждены.
Оригинал и VPS не изменены.
