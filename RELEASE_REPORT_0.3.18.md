# VEXA Taxi + VEXA MAP 0.3.18 — Offline Search & Route Preview

**Основа:** VEXA 0.3.17, графитовая/бирюзовая палитра и весь состав проекта сохранены. Изменения сделаны только в копии исходников в рабочей среде; Windows, VPS, GitHub и действующие сервисы не затрагивались.

## Добавлено в исходники

1. `android/shared/vexa-map-offline/src/main/java/ru/vexa/offline/OfflineNavigation.kt` — офлайн-поиск по SQLite и ограниченная маршрутизация по дорожному графу из установленного MBTiles. Считывание только из приватного каталога приложения; отсутствие пакета/индекса не скрывается.
2. `OfflineGraph.kt`, `OfflineSearchTerms.kt` — Dijkstra по времени на направленных рёбрах, привязка к ближайшему узлу, нормализация поиска (русская ё→е), ограничения памяти.
3. `android/client/.../AddressSearch.kt`, `VexaRouting.kt`, `MainActivity.kt` — офлайн-поиск и маршруты, переключение в «Авто/Онлайн/Офлайн» и маркировка предварительных маршрутов. Переключение режима инициирует пересчёт предпросмотра.
4. `android/driver/.../DriverMap.kt` — локальная линия дорожного маршрута и предварительное время/расстояние в офлайн-режиме; онлайн-путь сохраняется.
5. `OfflineMapsScreen.kt` — показывает отдельно доступность «Адреса» и «Дороги» у установленных округов.
6. `VEXA_MAP/tools/prepare_offline_navigation.py` — операторский импорт лицензированных CSV в существующий MBTiles **до публикации SHA-256**. Всё в одной версии/пакете, старые растровые MBTiles остаются совместимы.
7. В обоих Android-проектах обновлено `versionCode=18`, `versionName=0.3.18`; подготовлены техническая инструкция и новые тесты.

## Тесты (локально)

- `python -m unittest discover -s VEXA_MAP/tests -q`: **29/29** (в том числе 6 тестов нового импортера).
- `python -m unittest discover -s tests -q`: **41/41** (контракты исходников, не полноценный запуск приложений).
- Автономный `kotlinc` + Java для `OfflineGraph.kt` и `OfflineSearchTerms.kt`: **7 утверждений**.
- Код `OfflineNavigation.kt` скомпилирован `kotlinc` с **тестовыми заглушками** Android Context/SQLite/JSONObject и настоящей coroutines-библиотекой — не является Android Gradle build или подтверждением корректности работы SQL на устройстве.
- Python import/rollback проверен на **синтетической**, не российской реальной дорожной сети.

## Ограничения

- В исходном архиве **нет геоданных России, региональных растровых MBTiles, адресных CSV или дорожных графов**. Для реального офлайн-поиска нужно создать и загрузить расширенный MBTiles конкретного округа.
- Локальная маршрутизация — **предпросмотр для небольших участков**: до 90 км, максимум 60 тыс. узлов / 240 тыс. рёбер в коридоре, ближайшая дорожная точка ≤350 м. Нет turn restrictions, дорожных знаков, учёта габаритов, пробок и межрегиональных переходов; не использовать для критичных водительских инструкций.
- Онлайн/офлайн-карта PNG/JPG/WebP из 0.3.17 сохраняется; векторные PBF, встроенные шрифты, подписи, спутниковая подложка и 3D остаются отдельной задачей.
- **Серверный расчёт стоимости и заказов не менялся**; офлайн-результат не отправляется в Backend как тариф. Без связи с Backend нельзя создавать/исполнять заказы или проводить платежи.
- Подпись пакетов издателем не внедрена (SHA-256 — лишь целостность). Перед публичной раздачей обязательны аутентификация/подписи, квоты, лицензии и реальные Android-полевые тесты.
- **APK не собраны**, на телефоне/в режиме полёта не проверено. В исходной базе нет `gradle-wrapper.jar` для автономной сборки и отсутствует Android SDK в нашей среде.
