# VEXA 0.3.16 — Offline Maps Manager

**Основа:** VEXA 0.3.15. **Тип:** исходники, без APK.

Внедрён общий модуль `android/shared/vexa-map-offline`, подключённый к `android/client` и `android/driver`. В настройках обоих приложений есть экран восьми федеральных округов, просмотр доступных и скачанных версий, загрузка, пауза и продолжение, проверка SHA-256, удаление и обновление. Введён контроль свободного места и атомарная установка после проверки; скачивание по умолчанию на сервере отключено и требует публикации реальных данных. Android версии обновлены до 0.3.16.

**Тесты:** 23/23 VEXA MAP; 28/28 общих и контрактных; Kotlin правила региона 9/9; проверка ZIP. **Не проверены:** Android Gradle-сборки APK (в исходной базе отсутствуют gradle-wrapper.jar), реальный запуск на двух телефонах, большой пакет, доставка по HTTPS, реальная офлайн-навигация.

Читать `VEXA_MAP/ANDROID_OFFLINE_MANAGER_0.3.16.md`.
